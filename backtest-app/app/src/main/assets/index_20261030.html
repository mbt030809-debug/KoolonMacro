종목 · 기간

매수 조건 (충족 시 보유)

매도 조건 (충족 시 전량 현금화)

매도 조건이 없으면 매수 조건이 깨질 때 매도. 둘 다 충족하면 매도 우선. 조건은 위에서 아래로 순서대로 AND/OR 결합.

옵션

신호는 종가 기준이며 지연 0일 = 신호 당일 종가 체결(수익은 다음 거래일부터), n일 지연 = n 거래일 뒤 종가 체결. 세금은 연 단위 손익통산 후 해당 연도 마지막 거래일에 납부(전략만 적용, 보유 비교는 세전). 미실현 이익은 과세 안 함.
